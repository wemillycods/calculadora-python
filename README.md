
# Calculadora em Python

Minha primeira calculadora em Python, desenvolvida do zero! 💙

## Funcionalidades
- Entrada de dois números inteiros
- 4 operações: soma, subtração, multiplicação e divisão
- Repete automaticamente até o usuário encerrar
- Validação de opção inválida

## Aprendizados
- `print()` e `input()`
- Conversão com `int()`
- Estrutura `if / elif / else`
- Laço de repetição `while True`
